# TTEC101 Assignment 2 – Weather Data Analysis Using Open-Meteo API

## Project Overview

This project analyses weather forecast data collected from the Open-Meteo API for Sydney, Australia. The project demonstrates the use of R programming for API data retrieval, data processing, statistical analysis, and data visualisation.

## Tools and Packages Used     

* R
* httr
* jsonlite
* dplyr
* ggplot2
* R Markdown

## Project Files

* analysis.R – Data collection, processing and visualisation code
* weather_report.Rmd – Reproducible report source file
* weather_report.html – Final generated report
* images/ – Visualisation images used in the report

## Key Findings

1. Weather conditions remained relatively stable during the forecast period.
2. Rainfall activity was limited and occurred on only a few days.
3. Higher rainfall periods generally corresponded with lower temperatures.
